# Cuban Salsa Dancing Static Website
## Project Overview

This project is a website about Cuban Salsa dancing. It provides information about the origins of salsa, its health benefits, appropriate footwear and local places to learn and practise salsa in the East Sussex area.

## Technologies Used

- **HTML5:** Structure and semantic elements of the website.
- **CSS3:** Controls colours, fonts, formatting and layout.
- **Bootstrap 5.3.8:** Responsive design.
